
# B4WarmED Soil Enzyme Analysis

## Project overview
Analysis of soil enzyme activity under experimental
warming and drought treatments.

## Dataset
The dataset includes:
- Year and sampling information
- Warming treatments
- Water treatments
- Canopy conditions
- Soil temperature and moisture
- Soil respiration (EFFLUX)
- Enzyme activities: AG, BG, CB, NAG, PHOS, XYL, LAP

## Analysis
R scripts are used for:
1. Data import and cleaning
2. Summary statistics
3. Enzyme activity visualization
4. Statistical analysis

## Software
R and RStudio

## How to run
Open the RStudio project and run the scripts
in numerical order.
